# Icon additions — 18 October 2026

These 27 icon assets were generated with the built-in image_gen tool from the project owner's approved concept board, then packaged as transparent 24 × 24 PNG files. They are new AI-assisted additions, not artwork attributed to the original icon artist. Existing artwork, licensing and attribution were retained unchanged. Shared material variants intentionally reuse the same asset.

The approved solver motifs are rhombic-dodecahedral cells for Finite Volume and triangulated wall/floor boundary panels for Boundary Elements.

## Packaging

Transparent margins were trimmed to the nonempty alpha bounds. Each glyph was fitted proportionally within a 22 × 22 area of a 24 × 24 RGBA canvas, preserving a transparent border. No original icon files were overwritten. Existing Spectrum to List, Pachyderm file, and Pachyderm for Rhino result artwork was reused directly. GH1 uses Resources.resx and its generated accessors; GH2 uses its existing embedded PNG resource loader.
